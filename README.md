# cam_pub
This repository was created as part of the technical challenge for the Robotics Systems Engineer position at Rapyuta Robotics. The goal is to develop a simple object-tracking system using a webcam.

The `cam_pub` package is responsible for publishing images from the webcam and the camera status. It includes two main nodes: `CamPub`, which publishes images and camera status, and `CamPubThreaded`, which is a threaded version of `CamPub` for improved performance.
